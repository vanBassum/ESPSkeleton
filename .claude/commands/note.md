description: Capture a shift in understanding as an understanding-delta note
---

Invoke the `reasoning-note` skill. Draft a note capturing the most recent shift
in understanding from this conversation (or the one described in the arguments
below) as an understanding delta: Before / What changed it / Now / Follows
(optional). Apply "compress the path, never the insight" — preserve every change
to the mental model at full fidelity, delete the surrounding conversation. It
need not contain a decision. Title it as a proposition (the shift itself). Write
it straight to `docs/reasoning/` without asking for approval, then report the
titles in one line. Never edit existing notes — relate to earlier ones via
`builds-on` or `supersedes`.
